One funny, painfully honest line imagining the comment a developer left
above fragile production code — a [make.fun](https://make.fun/bounty/u-mfnakmal-the-comment-above-the-code-35e38026) bounty entry.

## The entry

> // This was a temporary fix. It turned five last March. It has a mortgage now.

81 characters. A "temporary fix" that turned five and now has a mortgage:
the most recognisable legacy-code failure there is, with a concrete time
marker and a kicker that lands on the last words.

## How it works

`main.py` (Python 3, standard library only) writes the single line to
`/output/entry.txt` and reads the file back to verify it byte for byte.
No network, no randomness, no dependencies.

```sh
python3 main.py --self-test   # check the kit gate + drafting rules
ENTRY_OUTPUT=entry.txt python3 main.py
```
